# 文档一：前端交互原型文案（模板管理页 + 任务下发页）

> 
> 目标：严格区分「修改本次下发问卷」和「修改通用模板」，避免运营误覆盖基准模板

## 页面1：问卷模板管理页（维护通用基准DAG）

**页面用途**：新增、查看、编辑、版本管理、停用【通用模板】，这里改动会影响后续所有新下发任务。
列表字段：
模板名称｜模板分类｜版本｜状态（启用/停用）｜创建时间｜操作
操作按钮：【查看】【编辑模板】【复制新建模板】【停用】

### 弹窗：编辑模板（无人机核查问卷，template_id=1）

- 画布：问卷DAG编辑器（题目节点、分支跳转连线、条件配置）
- 底部按钮：
【保存】→ 校验DAG无环，更新该模板版本，写入 `template_node` / `template_edge`，**后续选这个模板下发都会拿到新版结构**
【取消】→ 丢弃改动，不保存

> 
> ⚠️ 提示文案（红色）：
> 当前编辑的是通用基准模板，保存后，**以后所有新下发任务默认使用此版本；已经下发完成/草稿中的问卷实例不受影响**。

## 页面2：核查任务下发页（核心流程页，用户最常用）

**页面用途**：选择模板、填写任务信息、【可选临时修改问卷结构】、下发任务

### 步骤1：基础信息区

1. 选择模板下拉：`无人机核查问卷` / `人员兴趣爱好调查问卷`
2. 自动回填：模板名称、模板版本（溯源用）
3. 填写任务基础字段：核查对象、核查时间、核查人等业务字段

### 步骤2：问卷预览&编辑区（关键）

> 
> 文案重点区分，防止混淆
> 提示文案：
> ✅ 当前为【本次任务独立问卷草稿】，所有结构修改**仅对本次下发生效，不会改动原始通用模板**；如需永久更新模板，请使用【另存为模板】按钮。

画布：和模板编辑器一样的DAG画布，可以：

- 新增题目（例子：国籍）、删除题目、修改题干选项
- 新增/修改/删除跳转分支、修改分支条件
- 实时自动校验DAG，有环直接提示，禁止保存草稿

### 页面底部按钮（3个，语义严格隔离）

1. 【下发任务】（主按钮，蓝色）
   - 校验：任务信息合法 + DAG无环
   - 逻辑：草稿 `draft` → `published`，问卷结构冻结，正式下发给填写人
   - 不碰原模板，**本次修改只留在这个instance实例**
2. 【另存为新模板】（次要按钮）
   - 弹窗：输入模板名称、选择分类
   - 逻辑：把当前草稿实例的DAG，复制一份，生成一条全新的 `template` 通用模板
   - 示例：本次加了国籍，另存为「无人机核查问卷（含国籍项）」，以后可以直接选这个新模板
3. 【更新原模板】（危险按钮，弱化+强二次确认）
   - 二次确认弹窗文案：> 
   > ⚠️ 高危操作：将会用当前草稿问卷结构，覆盖原始【无人机核查问卷】通用模板，**之后所有新下发任务都会使用这个新版模板，已有的问卷实例不受影响，确认继续吗？**
   - 确认后：把当前instance的DAG覆盖回template，版本号+1
4. 【取消】：丢弃当前草稿，关闭页面，不生成实例

### 补充交互细节

- 刚选中模板，还没有改动问卷结构：页面提示「问卷结构与原始模板一致」
- 用户新增/删除题目、修改分支之后：页面标记【已调整问卷结构】，同时给实例打上 `is_modify_template_snapshot = true`
- 下发成功之后：任务详情页，可以查看【问卷快照】，同时展示溯源信息：`来源模板：无人机核查问卷 v1`

## 函数1：选择模板，创建下发草稿实例（核心入口）

```
/**
 * 根据模板创建草稿问卷实例
 * @param templateId 选中的通用模板ID
 * @param taskBaseInfo 任务基础信息（核查对象、核查人等）
 * @returns instanceId 新生成的草稿实例ID
 */
async function createDraftInstanceFromTemplate(templateId: bigint, taskBaseInfo: TaskBaseDTO) {
  return await pg.transaction(async (tx) => {
    // 1. 新建实例主记录，状态draft，标记初始未修改
    const instance = await tx.query(`
      INSERT INTO questionnaire_instance (template_id, status, is_modify_template_snapshot, ...业务字段)
      VALUES ($1, 'draft', false, ...)
      RETURNING id
    `, [templateId]);
    const instId = instance.id;

    // 2. 复制模板节点到实例节点，生成id映射临时表
    await tx.query(`CREATE TEMP TABLE node_map (tpl_node_id BIGINT, inst_node_id BIGINT)`);
    await tx.query(`
      INSERT INTO instance_node (instance_id, source_template_node_id, node_type, title, config, sort_no)
      SELECT $1, id, node_type, title, config, sort_no
      FROM template_node WHERE template_id = $2
      RETURNING source_template_node_id, id INTO node_map
    `, [instId, templateId]);

    // 3. 复制模板边，把模板nodeId替换成映射后的实例nodeId
    await tx.query(`
      INSERT INTO instance_edge (instance_id, source_template_edge_id, from_node, to_node, condition)
      SELECT
        $1,
        e.id,
        m1.inst_node_id,
        m2.inst_node_id,
        e.condition
      FROM template_edge e
      JOIN node_map m1 ON m1.tpl_node_id = e.from_node
      JOIN node_map m2 ON m2.tpl_node_id = e.to_node
      WHERE e.template_id = $2
    `, [instId, templateId]);

    return instId;
  })
}
```

## 函数3：草稿下发，转为正式实例

```
/**
 * 草稿下发，冻结问卷结构
 * @param instanceId
 */
async function publishInstance(instanceId: bigint) {
  return await pg.transaction(async (tx) => {
    // 校验状态
    const inst = await tx.queryOne(`SELECT status FROM questionnaire_instance WHERE id = $1`, [instanceId]);
    if (inst.status !== 'draft') throw new Error('仅草稿可下发');

    // 下发前二次环校验（兜底）
    const hasCycle = await checkDagHasCycle(instanceId, false);
    if (hasCycle) throw new Error('问卷分支存在闭环，无法下发');

    // 修改状态、填充下发时间，结构锁定
    await tx.query(`
      UPDATE questionnaire_instance
      SET status = 'published', published_at = now()
      WHERE id = $1
    `, [instanceId]);
  })
}
```

        VALUES ($1, $2, 1) RETURNING id

## 配套补充说明

1. 渲染问卷（答题端）：根据 `instanceId` 递归CTE遍历 `instance_node + instance_edge`，和模板表完全无关，**保证实例结构稳定**
2. 答卷存储：答卷表只关联 `instance_id`，不关联模板；历史答卷永远和下发那一刻的问卷结构绑定
3. 版本追溯：模板自带version；实例记录来源template_id，可以随时回看当初是基于哪个模板下发
